## 1. Purpose

A place for real student experiences and suggestions to improve the handbook. **Personal experience is kept separate from official information** and is not a general rule or legal advice.

## 2. Who needs this?

- All readers — and anyone with an experience or correction to share. Experiences from students of **every nationality** are welcome, especially country-specific tips (visa waiting times, document legalisation, banking) for [Section 8](../08-by-nationality/README.md).

## 3. How to contribute

1.  **Report an error or broken link:** open a GitHub issue with the page number, a description and the correct source.
2.  **Add an experience:** use the template below in a GitHub issue or pull request, or in the "7. Student experiences" section of the relevant page.
3.  **Date every experience** — rules change.
4.  **Don't post personal data** (passport numbers, exact addresses, etc.).
5.  **⚠️ items** on the pages need confirmation or completion; if you have an official source, add it.

**Experience template**

| Field | Example |
|---------------|----------------------------------------------------|
| Related page | 10. Residence permit |
| Your nationality (optional) | e.g. "Brazilian" — helps others with the same rules |
| Date | October 2026 |
| Experience | What happened, how long it took, what helped |
| Name (optional) | Your name or "anonymous" |
