# Contributing

Thank you for helping international students in Hannover!

- **Small fix** (a number, a deadline, a broken link): open the page on GitHub, click ✏️ *Edit*, and propose the change as a pull request. Add the official source and today's access date.
- **Not sure / no time to edit?** Open an [issue](../../issues/new/choose) and describe the problem.
- **New page:** copy [TEMPLATE.md](TEMPLATE.md) into the right section folder and add it to that section's `README.md` and to [handbook/README.md](handbook/README.md).
- **Country-specific information** (visa waiting times, document legalisation, home-country scholarships, banking): add it to the matching page in [Section 8](handbook/08-by-nationality/README.md), with a date and source.

Step-by-step help with Issues and Pull Requests: [68. GitHub guide](handbook/07-resources/68-github-guide.md).

## Writing rules

1. **Fixed structure:** every topic page has these sections: 1. Purpose · 2. Who needs this? · 3. Steps · 4. Documents and costs (with a "Required / possible" column) · 5. Responsible office (official name, address, contact) · 6. Sources and official links · 7. Student experiences (unofficial). Example: [TEMPLATE.md](TEMPLATE.md).
2. **A source for every claim:** every figure, deadline, fee or rule needs a source link right next to it. Source priority:
   - Leibniz University Hannover — [uni-hannover.de](https://www.uni-hannover.de/)
   - City and Region of Hannover — [hannover.de](https://www.hannover.de/) and hannover.gov.de
   - The law — [gesetze-im-internet.de](https://www.gesetze-im-internet.de/aktuell.html)
   - The Federal Government's portal — [make-it-in-germany.com](https://www.make-it-in-germany.com/en/)
   - The responsible office (Studentenwerk, AStA, BZSt, German missions, …)
   - Other sources only with the label "unofficial source".
3. **Sources table:** section 6 of each page is generated by `tools/build_sources.py` from the links in sections 1–5 and the latest `link-report.tsv`. Don't edit it by hand — run the tools (see below).
4. **Symbols:** 🌍 = depends on nationality or residence status; ⚠️ = needs confirmation or completion; ℹ️ = general tip. Important warnings ("not legal advice") go in a `> [!WARNING]` box and the review date in the `> [!TIP]` box at the top.
5. **Personal experience** stays separate from official information, only in section 7, with a date. No personal data (passport numbers, exact addresses, …).
6. **Language:** clear, plain English; give the German term in brackets the first time (e.g. "registration of address (Anmeldung)"). Write for students of every nationality; mark country-specific points with 🌍.
7. **Links to other pages** use relative paths, e.g. `[10. Residence permit](../01-arriving-in-hannover/10-residence-permit.md)`.

## Checking links and building

```bash
bash tools/check_links.sh          # status of every external link -> link-report.tsv
python3 tools/build_sources.py     # regenerate section 6 (sources) on every page
python3 tools/disclaimer.py        # refresh the disclaimer box and last-updated date at the top of every page
python3 tools/build_search.py      # rebuild the search index (search/search-index.js) for both handbooks
python3 tools/build_pdf.py         # build pdf/Hannover-Handbook-International-Students.pdf
```

Some sites (e.g. make-it-in-germany.com, LinkedIn, goethe.de) block automated requests; check those links in a browser.

## Review

Residence, insurance, tax and work rules change quickly. Review each page at least once a semester and update the "Last reviewed" date in the box at the top.

## Disclaimer and changelog

The disclaimer box at the top of each page is generated by `tools/disclaimer.py` (between `<!-- disclaimer:start -->` and `<!-- disclaimer:end -->`); don't edit it by hand. Add a line to [CHANGELOG.md](CHANGELOG.md) for every notable change.
